ABOUT THE PROJECT

Suvarna River Path Analysis

This project studies historical changes in the Suvarna River and its estuarine mouth. It uses satellite imagery, Land Use and Land Cover (LULC), rainfall and weather information to understand river behaviour and predict possible future path changes.
